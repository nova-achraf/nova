How to merge PDF files

  1. Drop two or more PDF files.
  2. Use the ↑ ↓ buttons to put them in the right order.
  3. Press “Merge PDFs” — the combined file downloads immediately.

What gets preserved

Pages are copied exactly as they are: text, images, vector art and page sizes. Nothing is re-rendered or recompressed, so the quality is identical to the originals.

Password-protected files

A PDF that requires a password to open cannot be merged. Remove the password with the app that created it first, then try again.

Is it private?

Yes. The merge happens inside your browser using a local PDF library — your documents are never uploaded. This is safe for contracts, invoices and official papers.
