Common sizes

  • 1920 × 1080 — Full HD wallpaper or YouTube thumbnail background
  • 1280 × 720 — HD video and blog headers
  • 1080 × 1080 — Instagram square post
  • 1080 × 1350 — Instagram portrait post
  • 1200 × 630 — Facebook and Twitter link preview

Is resizing the same as compressing?

No. Resizing changes the number of pixels (the dimensions), while compressing reduces the file weight. Reducing dimensions usually shrinks the file too, which is why resizing is the fastest way to make a photo lighter. If you only want a smaller file at the same dimensions, use the image compressor.

Will I lose quality?

Downscaling always discards pixels, but that is usually what you want for the web. Upscaling beyond the original size adds no detail — it only softens the image, so avoid it unless you have no choice.
